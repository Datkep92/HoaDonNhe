# CN Tax Tools

**Miễn phí trong giai đoạn phát triển.** Công cụ hỗ trợ kế toán trên Windows 64 bit.

## Chức năng

- Tải hóa đơn mua vào/bán ra; quản lý nhiều MST, lọc và xuất Excel kèm trạng thái hóa đơn.
- Tổng quan, hàng hóa, đối tác, thuế GTGT và đối chiếu dữ liệu.
- Nhập/đọc sao kê ngân hàng, tra cứu MST, tải tờ khai.
- Chuẩn bị file thay thế hóa đơn theo mẫu MISA; cần kiểm tra trước khi nhập/phát hành.
- Chatbot hỗ trợ phân tích, so sánh bảng kế toán với hóa đơn, báo cáo và xuất chênh lệch. AI có hạn mức; cần kiểm tra kết luận, thao tác ghi cần xác nhận và file tạo nằm riêng.

## Tải và cập nhật

[Tải bản mới nhất](https://github.com/Datkep92/HoaDonNhe/releases/latest). Chọn file CN-Tax-Tools-Setup-vX.Y.Z.exe trong Assets; cài hoặc dùng Portable. Không cần Node.js/npm/Python, cần Chrome hoặc Edge.

Ứng dụng cập nhật qua GitHub Releases tại repo này. Giữ nguyên thư mục dữ liệu khi nâng cấp. v1.1.8 kiểm tra nền mỗi 15 phút và có thông báo Windows; Windows có thể ẩn thông báo khi bật Không làm phiền.

## Hỗ trợ

Bấm **Liên hệ Admin** trong ứng dụng để được hỗ trợ.
